NOTA SERVICE CV. DR PRINT — PWA MULTIPLATFORM

Isi folder:
- index.html: aplikasi nota
- stempel_ttd_dr_print.png: stempel dan tanda tangan CV. DR Print
- manifest.webmanifest dan sw.js: dukungan instalasi PWA dan cache offline
- icon-192.png dan icon-512.png: ikon aplikasi

PENTING TENTANG GRATIS DAN OFFLINE
1. Pemasangan PWA pada iPhone dan Android memerlukan alamat HTTPS. Hosting gratis dapat digunakan; tidak perlu membeli domain.
2. Buka aplikasi sekali saat online, lalu instal ke layar utama. Setelah aset tersimpan/cache, aplikasi dapat dibuka offline.
3. Data nota dan foto disimpan di browser/perangkat masing-masing. Data tidak otomatis tersinkron antara iPhone, Android, dan Windows.
4. Jangan hapus data situs/browser atau uninstall aplikasi sebelum mengekspor/mencadangkan data; data lokal dapat hilang.
5. Tombol WhatsApp membutuhkan internet. Membuat nota, menyimpan riwayat lokal, mengambil foto, dan cetak/simpan PDF dapat dilakukan offline setelah aplikasi terpasang dan dibuka pertama kali.

PUBLISH GRATIS (contoh GitHub Pages)
- Buat repositori GitHub baru.
- Unggah semua file di folder ini ke root repositori.
- Aktifkan Settings > Pages > Deploy from a branch > main > /(root).
- Tunggu alamat HTTPS GitHub Pages aktif.

INSTAL
Android: buka alamat HTTPS di Chrome > menu > Install app / Add to Home screen.
iPhone/iPad: buka alamat HTTPS di Safari > tombol Share > Add to Home Screen.
Windows: buka alamat HTTPS di Chrome atau Edge > ikon Install di address bar/menu.

CETAK
Halaman pertama adalah nota tanpa tanda tangan customer; halaman kedua hanya muncul bila ada foto barang. Lampiran foto menggunakan page break saat mencetak.
